## Key Topics — Hauptthemen

### 1. Morphological Word Decoding: Prefixes & Suffixes — Präfixe & Suffixe in der IT

**🇬🇧** Technical English relies heavily on standardized Latin and Greek affixes. Recognizing them allows instant deduction of meaning in unfamiliar technical documentation:
**🇩🇪** Fachenglisch nutzt standardisierte Affixe. Das Erkennen dieser Bausteine ermöglicht die sofortige Bedeutungsableitung in unbekannter Dokumentation:

| Affix Type / Typ | Common IT Affixes / Beispiele | Meaning / Bedeutung | Technical Example / IT-Beispiel |
|---|---|---|---|
| **Prefix / Präfix** | `de-` / `dis-` | Reversal, removal / Umkehrung, Entfernung | **Decouple** (entkoppeln), **Deallocate** (freigeben) |
| **Prefix / Präfix** | `inter-` | Between, interconnected / Zwischen, vernetzt | **Interface** (Schnittstelle), **Interoperability** |
| **Prefix / Präfix** | `multi-` / `poly-` | Many, multiple / Mehrfach, viele | **Multithreading**, **Polymorphism** |
| **Prefix / Präfix** | `re-` | Again, repetition / Wiederholung, Rückführung | **Redundancy**, **Refactoring**, **Rollback** |
| **Suffix / Suffix** | `-able` / `-ible` | Capability, capacity / Fähigkeit, Eignung | **Scalable** (skalierbar), **Compatible** (kompatibel) |
| **Suffix / Suffix** | `-tion` / `-sion` | Action, state, process / Zustand, Prozess | **Virtualization**, **Encryption**, **Transmission** |
| **Suffix / Suffix** | `-less` | Without / Ohne, abwesend | **Stateless** (zustandslos), **Serverless** |

### 2. Core IT Glossary Expansion — Fachvokabular

| Term / Fachbegriff | Technical Definition / Definition | Practical Context in IT |
|---|---|---|
| **Latency / Latenz** | The time delay between a request and the response / Verzögerungszeit | Network ping times, database query roundtrips |
| **Throughput / Durchsatz** | The volume of data processed or transferred per unit of time / Verarbeitungsmenge pro Zeit | Network bandwidth (Gbps), ETL pipeline batch capacity |
| **Deprecation / Veraltung** | Marking software features as obsolete before final removal / Ausmusterung von Softwarefunktionen | API versioning, legacy libraries |
| **Payload / Nutzlast** | The actual transmitted data payload excluding protocol headers / Eigentliche Nutzdaten ohne Header | JSON body in a REST API request |
| **Redundancy / Redundanz** | Duplication of critical components to ensure fault tolerance / Mehrfache Auslegung für Ausfallsicherheit | RAID arrays, backup server clusters |

### 3. Contextual Reading Strategies — Strategisches Leseverständnis

**🇬🇧** In professional IT operations, manuals and documentation are almost exclusively published in English. When facing complex text:
**🇩🇪** In der professionellen IT-Praxis ist Dokumentation fast durchgehend auf Englisch verfasst. Strategien zur Bewältigung komplexer Fachtexte:

- **Skimming (Überfliegen):** Reading headings, bold terms, and opening sentences to quickly grasp the overarching architecture.
- **Scanning (Gezieltes Suchen):** Searching specifically for technical keywords, metrics, error codes, and configuration parameters.
- **Contextual Inference (Kontextuelle Korrelation):** Deducing the answer to technical questions by cross-referencing known syntax patterns, acronyms, and logical relationships, even when individual words are unfamiliar.

- **Morphology speeds up comprehension:** Breaking technical words into prefix + root + suffix unlocks the meaning of 80% of new computing terms instantly.

**🇩🇪**
- **Englisch ist ein operatives IT-Werkzeug:** Fachkompetenz erfordert nicht perfekte Grammatik, sondern das schnelle Verstehen von Dokumentationen, Fehlermeldungen und Systemanforderungen.
- **Wortbausteine beschleunigen das Verstehen:** Das Zerlegen von Begriffen in Präfix + Stamm + Suffix erschließt die Bedeutung der meisten neuen IT-Fachwörter auf Anhieb.
